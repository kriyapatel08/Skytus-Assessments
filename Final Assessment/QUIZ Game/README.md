# Quiz Game (Python)

## Overview
A simple command-line Quiz Game built using Python. It loads questions from a JSON file, displays them randomly, calculates the score, and saves the highest score.

## Features
- Multiple-choice quiz
- Randomized questions
- Score calculation
- High score tracking
- JSON-based question storage

## Files
- `quiz.py` – Main program
- `questions.json` – Quiz questions
- `highscore.txt` – Stores the highest score

## Requirements
- Python 3.x

## Run
```bash
python quiz.py
```
